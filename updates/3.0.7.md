# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. Added player mission cooldown when a mission has been successfully finished or failed by the player (optional).
2. Added mission cooldown when a mission has been successfully finished / completed (optional).
3. Added on random and select missions previous and next buttons.
4. Added on random and select an info button to allow the players click the selected mission and checkout its rewards and basic information.
5. Added a new option for every legendary hunting location (where missions start) to start a mission randomly or selected by the player - it used to start missions only randomly.
6. Added a new function on server escrowed file when a player paid an amount of money for starting a legendary hunting mission. This function can be used by developers so the amount that the player has paid can actually go somewhere than nowhere.
7. Added a new configuration option to cancel a started mission if a player is dead - this was not an optional feature.
8. Added on the NUI the cost display because right now, player does not know if there is a cost or not when starting a mission.
9. Modified eye target feature and now it allows you through `client/tp-client_escrow_ignore.lua` to implement your own eye target script / exports instead of **ox_target** which was the only eye-target script supported.
10. Modified the NUI design by making the size bigger so it can fit the new features - it also has now a better multi-resolution support.
11. Removed `tp_inputs` dependency, it was required when a location for starting a mission required money - inputs were for accepting / declining before starting, now the cost is displayed in the NUI which means the player knows if there is a cost or not before starting a mission.

## Notes

1. Add the new configuration options on `config.lua` below `Config.tp_clans`

```lua
-- Set the desired cooldown time after a player finishes or fails a mission in order to start again.
-- If player is in cooldown, he / she will not be able to start a mission until the duration / cooldown is finished.
Config.PlayerMissionCooldown = false -- time in minutes (3.0.7)

-- Set the desired cooldown time when a mission has been successfully finished / completed.
-- If a mission is in cooldown, the player will not be able to start the specified mission until the duration / cooldown is finished.
Config.MissionSuccessCooldown = false -- time in minutes (3.0.7)

-- Cancel the mission if the player who started it died for any reason.
Config.CancelMissionOnPlayerDeath = true --  (3.0.7)

-- Inventory path is required for loading item images directly from your inventory and not from our script.
-- TPZ-CORE : tpz_inventory/html/img/items/
-- VORP: vorp_inventory/html/img/items/
-- RSG: rsg-inventory/html/images/
-- (!) OX Inventory will never work, they using web connections and blocking our connection.
Config.InventoryImgPath = "tpz_inventory/html/img/items/" -- (3.0.7)

```

2. Add the following option in every location below `Coords` on `Config.Locations` - this option is for starting missions randomly or not.

```lua

RandomMissionSelect = true, -- 3.0.7
```
